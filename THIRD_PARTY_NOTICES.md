# Recursos de terceros

El código, las mallas originales de Nebula Defender y los efectos de audio sintetizados se incluyen como parte de este proyecto académico. La publicación del repositorio no añade una licencia general a su contenido original.

## Liberation Sans

La fuente Liberation Sans y su atlas TextMeshPro conservan sus avisos de autoría y la **SIL Open Font License 1.1** en [LiberationSans - OFL.txt](Assets/TextMesh%20Pro/Fonts/LiberationSans%20-%20OFL.txt).

## Unity y sus paquetes

Unity, Universal Render Pipeline, Input System, uGUI/TextMeshPro y Unity Test Framework se utilizan con las versiones de `Packages/manifest.json`. El repositorio no incluye Unity Editor ni su caché de paquetes. Los recursos esenciales TextMeshPro y la configuración URP conservan sus identificadores y avisos suministrados con Unity.

Las distribuciones contienen los componentes de ejecución generados por Unity. Unity Editor y Blender no son necesarios para ejecutar Windows. Blender solo se usa para crear o editar las fuentes de modelos.
